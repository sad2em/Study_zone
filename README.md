# Study Zone

مساحة دراسة شخصية باللغة العربية، تبدأ بثلاث جلسات في استخبارات المصادر المفتوحة. تضم قارئ دروس وتمارين ومراجعة وملاحظات محلية.

## تشغيل محلي بدون تثبيت

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

فعّل **Settings → Pages → Deploy from a branch → main → /(root)**. الملفات تستخدم مسارات نسبية لتعمل ضمن `/Study_zone/`.

> يتم حفظ التقدم محلياً في متصفح المستخدم (`localStorage`) ولا تتم مزامنته بين الأجهزة. لا ترفع بيانات خاصة إلى مستودع عام.
