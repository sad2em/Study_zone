# Study Zone

مساحة دراسة شخصية باللغة العربية، تضم سبع جلسات في استخبارات المصادر المفتوحة والتحقق الرقمي والمؤسسات والجغرافيا المكانية وتوثيق النزاعات، مع قارئ دروس وتمارين ومراجعة وملاحظات تُحفظ محلياً.

## الجلسات

1. **OSINT Foundations** — مقدمة في استخبارات المصادر المفتوحة.
2. **Digital Forensics** — الأدلة الجنائية الرقمية.
3. **SOCMINT & Narratives** — استخبارات وسائل التواصل وتحليل الشبكات والسرديات.
4. **V-HUMINT & Social Engineering** — الاستخبارات البشرية الرقمية، كشف الهندسة الاجتماعية، التحقق من المصادر، والتمارين الدفاعية المصرّح بها.
5. **Corporate Intelligence (CORPINT)** — تحليل الكيانات والملكية المستفيدة والإفصاحات المالية والعقوبات والبصمة الرقمية وسلاسل التوريد.
6. **Geospatial Intelligence (GEOINT)** — تحديد الموقع، صور الأقمار الصناعية، التحليل متعدد الأطياف، التغيرات البيئية، والهندسة المكانية.
7. **Military OSINT & Conflict Verification (MILINT)** — التحقق التاريخي من تقارير النزاعات، توثيق الأدلة المنشورة، بيانات الطيران والملاحة وحدودها، ونقل السلاح وسلاسل التوريد.

## بنية المشروع

الموقع واجهة ثابتة فقط باستخدام HTML وCSS وJavaScript في المتصفح، ولا يعتمد على Backend أو قاعدة بيانات أو خادم Node. أدوات Vite وNode الموجودة في المشروع مخصصة للتطوير والاختبار محلياً فقط وليست جزءاً من الموقع المنشور.

## معايير المحتوى والمساهمة

قبل إضافة درس أو استخدام مساعد ذكاء اصطناعي لتعديل المشروع، اقرأ [AGENTS.md](./AGENTS.md) و[معيار إعداد الدروس](./docs/COURSE_AUTHORING_STANDARD.md). يحددان أسلوب الكتابة، توثيق المصادر، تصنيف الأولويات، الاختبارات، وحدود التطبيق.

## تشغيل محلي بدون تثبيت

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

فعّل **Settings → Pages → Deploy from a branch → main → /(root)**. الملفات تستخدم مسارات نسبية لتعمل ضمن `/Study_zone/`.

> يتم حفظ التقدم محلياً في متصفح المستخدم (`localStorage`) ولا تتم مزامنته بين الأجهزة. لا ترفع بيانات خاصة إلى مستودع عام. التمارين الأمنية في الجلستين الرابعة والخامسة تستخدم بيانات اصطناعية أو بيئات مصرحاً بها فقط. الجلسة السادسة مخصصة للتحليل المكاني المدني والتاريخي والبيئي، ولا تتضمن تتبعاً عسكرياً أو استهدافاً. الجلسة السابعة مخصصة للتحقق التاريخي والمساءلة والبحث في السجلات المنشورة، ولا تتضمن تتبعاً عسكرياً آنياً أو تحديد مواقع تشغيلية أو التعامل مع ذخائر.
