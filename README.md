# Study Zone

مساحة دراسة شخصية باللغة العربية، تضم أربع جلسات في استخبارات المصادر المفتوحة والتحقق الرقمي، مع قارئ دروس وتمارين ومراجعة وملاحظات تُحفظ محلياً.

## الجلسات

1. **OSINT Foundations** — مقدمة في استخبارات المصادر المفتوحة.
2. **Digital Forensics** — الأدلة الجنائية الرقمية.
3. **SOCMINT & Narratives** — استخبارات وسائل التواصل وتحليل الشبكات والسرديات.
4. **V-HUMINT & Social Engineering** — الاستخبارات البشرية الرقمية، كشف الهندسة الاجتماعية، التحقق من المصادر، والتمارين الدفاعية المصرّح بها.

## تشغيل محلي بدون تثبيت

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

فعّل **Settings → Pages → Deploy from a branch → main → /(root)**. الملفات تستخدم مسارات نسبية لتعمل ضمن `/Study_zone/`.

> يتم حفظ التقدم محلياً في متصفح المستخدم (`localStorage`) ولا تتم مزامنته بين الأجهزة. لا ترفع بيانات خاصة إلى مستودع عام. التمارين الأمنية في الجلسة الرابعة مخصصة لبيانات اصطناعية وبيئات مصرح بها فقط.
